# 📝 CheckTest AI -  המהפכה בבדיקת מבחנים הפרויקט בתהליך בניה

**CheckTest AI** היא מערכת RAG (Retrieval-Augmented Generation) חכמה, שנועדה להקל על מורות להיסטוריה בתהליך בדיקת המבחנים. המערכת מאפשרת סריקה של מבחנים בכתב יד, השוואתם לסילבוס הלימודי המקורי, וקבלת משוב מדויק וציון מומלץ בזמן אמת.

---

## 🌟 למה המערכת הזו מיוחדת?
בדיקת מבחנים פתוחים היא משימה מורכבת שדורשת דיוק והקשר. המערכת פותרת שתי בעיות מרכזיות:
1. **פענוח כתב יד עברי:** שימוש במודלים רב-מצביים (Vision) לזיהוי טקסט מתמונות.
2. **מניעת "הזיות" (Hallucinations):** הבטחה שהציון ניתן אך ורק על בסיס חומר הלימוד שהועלה למערכת (Grounding).

---

## 🛠️ הארכיטקטורה הטכנולוגית (Tech Stack)

הפרויקט נבנה בגישת **Best-of-Breed**, תוך בחירת הכלי המדויק לכל משימה:

* **Frontend:** `React` עם `TypeScript` ו-`Vite` לממשק מהיר וידידותי.
* **Backend:** `FastAPI` (Python) - שרת אסינכרוני לביצועים גבוהים.
* **AI Models:** * **Google Gemini 1.5 Flash:** משמש כ"בודק" - מבצע OCR לכתב היד ומנתח לוגית את התשובה מול המקור.
    * **Cohere Multilingual V3:** משמש ל-`Embeddings` - הבנת הקשרים סמנטיים עמוקים בשפה העברית.
* **Vector Database:** `Pinecone` - לניהול ושליפה מהירה של אלפי פסקי מידע מהסילבוס.
* **Framework:** `LlamaIndex` - לניהול ה-Data Pipeline וה-Workflows המורכבים.

---

## 🏗️ איך זה עובד? (The Pipeline)

1.  **שלב ההקמה (Ingestion):** המורה מעלה את סילבוס הלימודים. המערכת חותכת אותו ל-Chunks, הופכת אותם לווקטורים בעזרת Cohere ושומרת ב-Pinecone.
2.  **שלב הניתוח (Analysis):** המורה מעלה צילום של מבחן תלמידה.
3.  **שליפה (Retrieval):** המערכת מחלצת את השאלה ומחפשת ב-Pinecone את פסקאות המקור הרלוונטיות.
4.  **הערכה (Evaluation):** Gemini משווה בין תשובת התלמידה למידע שנשלף ומחזיר משוב מפורט וציון בפורמט JSON מובנה.

## 🚀 התקנה והרצה

### Backend (Python)
1. כנסו לתיקיית השרת: `cd server`
2. התקינו ספריות: `pip install -r requirements.txt`
3. הגדירו קובץ `.env` עם המפתחות שלכם (Gemini, Cohere, Pinecone).
4. הריצו: `python main.py`

### Frontend (React)
1. כנסו לתיקיית הלקוח: `cd client`
2. התקינו חבילות: `npm install`
3. הריצו: `npm run dev`

* **עקיפת חסימות SSL:** התאמת הקוד לעבודה בסביבות אינטרנט מסוננות (כמו נטפרי) בעזרת הגדרות Transport מותאמות.
